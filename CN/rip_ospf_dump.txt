P004 [Heading 3]: Theory
P005 [Normal]: 1. Dynamic Routing
P006 [Normal]: Dynamic routing is a routing method in which routers automatically learn and update network routes using routing protocols. Unlike static routing, it allows routers to adapt to changes in network topology and automatically select suitable paths for packet transmission.
P007 [Normal]: Dynamic routing protocols are generally classified into:
P008 [Normal]: Interior Gateway Protocols (IGPs): Used for routing within a single Autonomous System (AS). Examples include RIP and OSPF. 
P009 [Normal]: Exterior Gateway Protocols (EGPs): Used for routing between different Autonomous Systems. The most widely used EGP is BGP.
P010 [Normal]: 2. Routing Information Protocol (RIP)
P011 [Normal]: RIP is a distance-vector interior gateway routing protocol (IGP) used to exchange routing information within an autonomous system. It uses hop count as its routing metric, where the route with the fewest hops is preferred. RIP supports a maximum of 15 hops, while a hop count of 16 represents an unreachable network. In Cisco Packet Tracer, RIP can be configured using commands such as router rip, network, and version 2.
P012 [Normal]: 3. Open Shortest Path First (OSPF)
P013 [Normal]: OSPF is a link-state interior gateway routing protocol that determines the shortest path to a destination using the Shortest Path First (SPF) algorithm. Routers exchange link-state information to build a topology database and calculate optimal routes. OSPF uses cost as its routing metric and supports hierarchical network design using areas, with Area 0 commonly serving as the backbone area.
P014 [Normal]: 4. RIP and OSPF Configuration
P015 [Normal]: The lab involves configuring routers with RIP and OSPF and advertising the connected networks so that routers can dynamically learn routes. After configuration, routing tables and network connectivity can be verified using Cisco IOS commands such as show ip route and connectivity-testing commands such as ping.
